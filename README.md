# 🚗 Checklist Diario de Vehículos - Kernel Energy

Aplicación web segura para gestionar checklists diarios de vehículos con autenticación, captura de fotos y panel administrativo.

## ✨ Características Principales

- 🔐 **Autenticación Segura** - Login con usuario y contraseña
- 👥 **Roles de Usuario** - Conductor o Administrador  
- 📸 **Captura de Fotos** - Cámara integrada y subida de imágenes
- 📋 **Checklist Completo** - Información, SOAT, revisión técnica, equipos
- 📊 **Panel Administrativo** - Gestión de usuarios y estadísticas
- 💾 **Almacenamiento Local** - Datos privados sin internet
- 📥 **Exportación** - CSV, JSON y PDF
